# 📊 Sales Analytics & Demand Forecasting using Machine Learning

## 📌 Project Overview

This project presents an end-to-end **Sales Analytics and Demand Forecasting** solution developed using Python and Machine Learning. The objective is to analyse historical sales data, identify the factors influencing sales performance, and build predictive models to forecast future sales.

A realistic synthetic dataset was created to simulate real-world retail sales, enabling comprehensive data analysis, visualisation, customer behaviour analysis, and sales prediction.

---

## 🎯 Project Objectives

* Analyse historical sales data to identify trends, seasonal patterns, and customer purchasing behaviour.
* Perform data preprocessing and exploratory data analysis (EDA) to uncover meaningful business insights.
* Build and compare multiple machine learning regression models for accurate sales forecasting.
* Forecast future sales to support inventory management, production planning, and business decision-making.
* Provide actionable recommendations to improve sales performance and optimise business operations.

---

## 📌 Key Findings

* Seasonal demand has a significant impact on sales performance.
* Temperature positively influences product demand.
* Weekends and special events contribute to higher sales.
* Marketing expenditure improves customer engagement and revenue.
* Random Forest Regressor achieved the highest prediction accuracy on the synthetic dataset.
